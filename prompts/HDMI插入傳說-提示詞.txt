HDMI插入傳說｜提示詞整理
整理來源：本次可見對話與目前專案／線上版本。以下是方便繼續開發的整合提示詞，不是逐字聊天紀錄；後續更正優先於早期要求。

一、可直接使用的總提示詞
請製作並維護「HDMI 插入傳說」手機直式節奏／時機遊戲。接頭持續晃動，玩家抓準對準電視 HDMI 接口的時機按「插！」；每關連續成功五次讓電視爆炸，共三關，逐關增加難度。沿用目前 hdmi 遊戲與共通網站規則。

二、目前玩法與風格基礎
可愛漫畫式手部、HDMI 接頭、電視與成功登場角色；主色、角色姿態與過關效果沿用目前線上版本。手機單鍵點按，電腦支援空白鍵出手；目前主版本以自動晃動為主，搖桿不顯示，不把舊版必須用搖桿的流程直接還原。
失誤連擊歸零；碰撞有短暫停頓與收回。第三關有短暫慢動作空檔，提示玩家把握時機。五個進度點與標題不能遮住電視、接口或主要畫面。
過關顯示簡易慶祝效果，最後獎励「HDMI 折價券，請找阿呆換購」，可重玩或回首頁。這段玩法骨架以目前專案現況補充；本次可見對話沒有早期完整建立指令，不把補充內容稱為逐字原始要求。

三、對話中明確要求的修正
將成功插入時原本「阿斯」的語音改為簡單成功音效，不要語音。可用短而清楚的兩音符成功提示；失败與過關提示分別保留適合的效果。
HDMI 遊戲也必須防文字選取、長按選單與圖片拖曳。主選單及結束畫面有「回首頁」，遊玩中有「退出」；不是只在外層網站放按鈕。
主選單 Logo 去背，遊玩畫面也放去背 QAF Logo，和 AI出氣拳一样。離開遊戲／回首頁／切背景停止聲音，音效預設開啟，首次操作解鎖手機音訊。

四、備份與延續原則
延續目前已發布版本，不以早期 README 的「音效預設關」或「左右搖桿操作」覆蓋後來確認的設定。本次備份整合可見對話與目前線上遊戲；已附目前主選單和遊玩截圖。角色原稿、原始完整風格 SKILL 若需重做，應先找回現有素材與規則再動手。

五、共通網站與發布提示詞
請遵守以下共通規則：所有新遊戲與一般修改先在 qafstudio2/qaf-game 完成、發布並提供測試網址。只有我說「請發佈到音樂工作站」時，才完成音樂工作站的整合與發布。
使用去背 QAF Logo：主選單、遊玩右下角與結束畫面都要有；網站標題可回首頁。主選單與結束畫面都有「回首頁」，遊玩中都有「退出」。離開遊戲、返回列表或切到背景時停止聲音及持續操作。
首頁直接展示遊戲卡片，包含名稱、介紹、遊戲畫面、全螢幕與分享；支援 Facebook 分享及複製連結。桌面並排、手機單欄直式；標題、進度點與說明不遮住遊戲或重要資訊。
手機遊戲高度穩定，不隨瀏覽器工具列伸縮而位移。禁止文字選取、圖片拖曳與長按選單，保留點按、多指、長按連發。音效預設開啟，第一次操作解鎖音訊；語音先預載、解碼後再播放。測試實際聲音訊號，不能只看字幕或播放狀態。
新增或修改遊戲時，同步更新根 index.html 的 .game-card：唯一 id、data-title、data-url、iframe data-src，保留既有遊戲。qaf-game 是唯一清單來源；好朋友版與音樂工作站透過 ?embed=friend 載入，不另外複製清單。保留嵌入模式、退出、返回列表、回首頁及音訊停止。
發布時更新資源版本；測試獨立首頁、?embed=friend，以及音樂工作站 #games 的開啟和退出。沿既有 GitHub Pages 流程發布，確認提交、部署成功與正式網址後才回報完成；有卡點須列出已完成與尚未發布項目。
