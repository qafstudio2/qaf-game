# 修吉他任務 1：修上弦枕

可愛低多邊形 3D 工坊，五種吉他與六種琴主隨機出現。三關為普通客人、資深玩家、超級收藏家。

## 操作與判定

- 聽琴主試彈，點修理後吉他移到工作檯，鏡頭轉到琴頭、上弦枕至第四格的側面。
- 按住磨慢慢降低中間溝槽，放開即停。橘色虛線表示側面看不到的槽高。
- 太低時先加骨粉、再加快乾膠，重新打磨。快乾膠不能單獨填槽。
- 測試時手指壓第三格，連續弦線向下傾斜。第一品絲弦隙與數字判定使用同一幾何公式。
- 三關合格區間：0.070–0.150 / 0.075–0.115 / 0.085–0.105 mm。畫面為放大示意，並非實際維修標準。
- 交付不合格會讓原琴主試彈並退回重修；合格收費範圍依序 $500–800 / $1,200–2,500 / $3,000–5,000，少量好心情琴主會額外付小費。
- 每次通關從七段原創合成分解和弦中挑選，同一輪三關不重複。
- 完成後顯示上弦枕大師獎勵，收入紀錄保存在此裝置的 localStorage；不跨裝置同步。

## 音訊與發布

六段男女客人語音在開始接單時全部預載、解碼，再由第一次操作解鎖的 Web Audio 系統播放。吉他音樂以撥弦合成產生，太高為悶硬音色、太低加入輕微分岔雜音。

主選單與結束畫面可回首頁，遊玩中可退出；離開、背景切換會停止音訊及長按打磨。共用目錄由根 index.html 提供，?embed=friend 讀取同一份清單。

Three.js 固定為 0.160.1，由 jsDelivr 載入；初次開啟需要網路。發布與好朋友版整合規則見根目錄 AGENTS.md。

## 驗證

本機以 Edge / Playwright 檢查真實音訊輸出 RMS、壓弦幾何、失敗重修、骨粉／膠順序、長按停止、三關收入與保存、320×568 / 390×700 直式畫面，以及獨立和共用目錄退出。手機實機音量與觸感仍需使用者試玩確認。
